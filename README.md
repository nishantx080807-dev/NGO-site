# NGO Field Reporting Portal

A responsive dashboard concept for coordinating community programs, field teams, and incoming reports.

The project is a single-file frontend prototype focused on making an operational workflow easy to scan: what is active, what needs attention, and what has recently been submitted.

## What’s inside

- calm, high-contrast dashboard layout for long working sessions
- project, report, task, and worker summary cards
- quick-create project form
- lightweight report-template builder
- task list and recent-report table
- responsive layout that collapses cleanly on smaller screens
- small interaction layer for navigation, project creation, and template fields

## Run locally

No build step is required.

```bash
python -m http.server 5500
```

Then open <http://localhost:5500>.

## Product direction

This is intentionally a frontend-first prototype. The next layer would be real project persistence, authenticated roles, field-worker views, offline capture, and report validation.
